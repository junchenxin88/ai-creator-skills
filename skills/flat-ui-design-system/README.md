# flat-ui-design-system｜扁平 UI / 图表 / HTML 卡设计规范

## 简介
面向图表、流程图、UI mockup、仪表盘、交互说明页以及嵌在对话/网页里的视觉组件：强制扁平、暗亮双模式、CSS 变量与复杂度上限，避免花哨渐变与把大段说明塞进组件。

## 何时用
- 画 diagram / mockup / chart / interactive / art 任一视觉
- 写公众号/图文 HTML 卡片、封面旁的信息卡、数据面板
- Canvas / 小工具 UI
