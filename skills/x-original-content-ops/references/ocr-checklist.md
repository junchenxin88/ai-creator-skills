# Original Content Rewards 速查表

权威：https://help.x.com/en/using-x/original-content-rewards  
整理：2026-11-02（发前请回官网核对）

## 申请门槛（常见表述）

| 项 | 要求 |
|---|---|
| 年龄 | 18+ |
| 地区 | 计划可用国家 |
| 订阅 | Premium / Premium+ / Premium Business（或官网列档） |
| 认证粉 | ≥ 500 |
| 曝光 | 近 90 天 ≥ 500,000 认证用户 Home Timeline 曝光；**回复不计** |
| 账号 | 个人/商业；政/政府组织通常不可 |
| 内容 | 持续发「原创」 |
| 录取 | 达标不保证录取；申述 1 次；再申约 42 天 |

## 合格付费曝光

- Premium 系用户  
- Home Timeline  
- 帖子约 ≥50% 可见  
- 同一账号对同一帖去重  
- 不计：推广/刷量/欺诈/Boosted 等（以条款为准）

## 原创：过 / 不过

| 过 | 不过 |
|---|---|
| 自己写/拍/画 | 全文搬运 |
| 有新增分析的评论 | 仅滤镜/叠字/改几词 |
| 自己的跨平台作品 | 别人内容的合集无观点 |
| | 非作者跨平台搬运 |
| | 纯自动化发布 |
| | 只谈如何赚 X 钱 / 刷奖励 |
| | 有害、色情、虚假、helpful Community Note |

## 停权雷区（摘要）

- 刷量、机器人、篡改推荐  
- 反复求赞求转求关  
- 虚假陈述、滥用违法  
- AI 武装冲突视频不声明（90 天 / 永久停付）
