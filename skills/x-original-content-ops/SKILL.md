# X 原创内容运营（Original Content Ops）

写 X 帖、串推、Articles、有信息量的回复之前**必须先跑本技能**。目标两件事：①尽量符合官方「原创」与合规，避免被踢出奖励/限流；②在不违规前提下尽量拿首页时间线曝光。

> **权威源（发前请再打开核对，数字会变）**  
> - https://help.x.com/en/using-x/original-content-rewards  
> - https://help.x.com/en/rules-and-policies/x-rules  
> - https://x.com/XCreators/status/2011957172821737574（《The ultimate guide to Articles on X》）  
> - 算法权重见开源仓 https://github.com/xai-org/x-algorithm（本技能只摘可执行结论）  
> 整理日期：2026-11-02。**已对照官网原文摘录**（同日浏览器打开 help 页）：`references/official-help-excerpt-2026-11-02.md`。门槛以官网为准。
> 地区：台湾在可用国家列表内；中国大陆未列。退出计划：私信 @Subscriptions。

## 硬规（一票否决）

1. **不代发**：只给可点开的发帖/回复链接或正文草稿，由账号主人自己点发送。
2. **不编造**：禁止虚构实测、数据、截图、模型能力；核不了就写「待实测 / 待复现」。
3. **不刷互动**：禁止反复叫人点赞、回复、收藏、关注、转发；官方 Original Content Rewards 明确禁止 soliciting engagements。
4. **不自动发帖**：奖励计划把「automated means」发的内容排除在合格曝光外；脚本可写草稿，不可代替真人发布。
5. **不抄袭/轻改**：全文搬运、换几个词、加滤镜/叠字、拼盘无观点、把别人内容跨平台再发——都不算原创。
6. **不主打教「怎么赚 X 钱」**：内容若**只**谈变现辅导/刷奖励/最大化 payout，官方不计合格曝光。
7. **AI 冲突视频要标注**：涉及武装冲突的 AI 生成视频若不声明为 AI，可被暂停奖励 90 天，再犯永久停付（官网条款）。

## 什么算原创（官方定义 · 操作版）

**算**：你自己写的文字、拍的图/视频、画的图；带**明显新增观点/分析/语境**的评论、拆解、对照；自己的作品从别的平台搬到 X（你是作者）。

**不算 / 不计奖励曝光**：
- 复制粘贴别人全文（含从 X 下载再传）
- 仅滤镜、变速、叠一句描述字幕
- 他人帖/片合集，无实质新框架
- 非作者把别人内容从别的平台搬来
- 带 helpful Community Note 的帖、虚假信息、色情有害、纯自动化产出

评论区回复：要有**结论 + 具体点 + 提问**（对标宝玉结论句结构），不是表情包式灌水。

## Original Content Rewards 门槛速查（申请前）

打开 Creator Studio → Original Content Rewards 看账号是否全部打勾。公开页常见要求（**以官网当日为准**）：

| 项 | 常见要求 |
|---|---|
| 年龄 / 地区 | 18+；计划覆盖国 |
| 账号类型 | 个人或商业；政/政府组织账号一般不可 |
| 订阅 | Premium / Premium+ / Premium Business（或官网列的等价档） |
| 粉丝 | ≥ **500 认证粉丝** |
| 曝光 | 近 **90 天** ≥ **50 万** 认证用户的 **Home Timeline** 曝光（**回复曝光不计**） |
| 内容 | 持续发符合上文的原创 |
| 申请 | 达标≠录取；拒绝可申述一次，失败后约 **42 天**可再申 |
| 结算 | 约每两周；最低约 **$30**；美用 X Money，其他多走 Stripe |

**合格付费曝光 ≠ 分析后台总曝光**：多为 Premium 用户在首页时间线、帖子至少约一半可见的**去重**曝光；推广/刷量/欺诈不计。

## 发前原创自查（每条必勾）

- [ ] 我是作者？若引用他人：我加了对方没有的分析/对照/可核数字？
- [ ] 改动是否超过「换词/滤镜/叠字」？
- [ ] 不是无观点合集？不是搬别人跨平台内容？
- [ ] 素材有权用（图/视频/音乐）？
- [ ] 主题不是「只教怎么在 X 赚钱」？
- [ ] 无自动化代发、无反复求赞求转？
- [ ] 事实可核；避免容易被 Community Note 打脸的绝对句？
- [ ] 若含 AI 生成冲突影像：已标明 AI？

## 涨曝光（合规做法）

算法更奖励**回复、引用、复制链接、关注**，点赞权重低；负反馈（不感兴趣/静音/拉黑/举报）极重。可执行：

1. **首句给结论或硬数字**，短句，说人话；禁止震惊体硬广。
2. **结尾一个具体二选一/场景问题**，方便真人回复（拿回复权重）。
3. **同作者连发要稀**，避免短时间刷屏触发同作者衰减。
4. **主帖少塞外链**；必要链接可放评论或文末（外链点击权重低，停留也常差）。
5. **话题稳定**（AI 工具实测 / 深度拆解；X 可兼加密），方便进对的兴趣圈。
6. **优先原创帖**吃冷启动窗口；纯回复很难进陌生人 For You。
7. **Articles**（Premium）：目的清晰 → 具体好奇标题 → 短段+小标题+加粗要点 → 证据/故事 → 狠删 20–30% → 强结尾提问/行动；发前可预热，发后 24–72h 置顶，拆成串推引流，早回复读者。（详见 @XCreators Articles 指南）
8. **禁止**买粉、互赞群、机器人、重复求互动话术。

## 小号冲门槛路线（本技能默认）

1. 先冲 **500 认证粉** 与可持续原创节奏，再谈申请奖励。
2. 每周固定：原创帖（工具真测/开源过程/深度观点）+ 有信息量的热点回复；回复间隔 ≥5 分钟，像真人。
3. 每周复盘：曝光、回复率、主页访问、净增粉；单条是否进推荐。
4. Creator Studio 数字与官网冲突时，**以 Studio / 官网为准**，并改本技能数字。

## 输出格式（给发布人）

每条草稿交付须含：
1. 一句话原帖/选题要点  
2. 正文（口语，1–2 句回复或完整原创）  
3. 原创自查勾选结果  
4. 一键发帖/回复链接（`https://x.com/intent/post?text=...`，回复加 `in_reply_to=`）  
5. 建议发送顺序与间隔
