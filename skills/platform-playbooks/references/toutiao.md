# 今日头条 平台说明书（执行清单）v1｜2026-11-01

> 只做 AI。两条线：①原创实测（微头条 + 文章）；②**以 X 爆文为新闻线索的原创评论**。

## 一、机制要点
- [ ] 流程：初审 → 冷启动（看**点击、分享、点赞**）→ 正常推荐 → 复审。标题党、封面党会在复审时被停推。【官方】https://baike.toutiao.com/detail/211/221/0
- [ ] 推荐量还要和同一时段内容池里的其他内容比，小众题材可能推到一半就停。【官方】同上
- [ ] 点击率 7–10% 算不错，15% 以上算很强。【非官方】https://www.toutiao.com/article/7110180561398022660/
- [ ] 文章：300–50000 字，最多可设 6 个标题做 A/B 测试；微头条：最多 9 张图。【非官方】https://www.toutiao.com/article/7186555452497609253/
- [ ] 收益：文章和微头条 少量粉就能开收益（微头条要求信用分 100）。【官方】https://baike.toutiao.com/detail/192/200/0
- [ ] AI 生成的内容要勾选「AI 生成」声明；模板化盘点类的 AI 低质内容会被处置。https://www.toutiao.com/article/7442290390092268042/
- [ ] 不写投资建议（财经属于需要资质的领域）。【官方】https://baike.toutiao.com/detail/242/255/0

### X 线索稿专用规则（作者，并与官方规则一致）
- [ ] **不翻译原句、不用原图或原视频**：未经授权翻译、改编、评议原作品都属于非原创。【官方】https://baike.toutiao.com/detail/242/566/0
- [ ] **不勾「首发」**：非首发内容声明首发，每篇扣 5 信用分。【官方】同上
- [ ] **不勾「原创」**：违规声明原创每次扣 20 分。【官方】https://baike.toutiao.com/detail/242/243/0
- [ ] 只拿**事实**当线索，用自己的结构写，补 3 层增量：背景 / 对比国产 / 对老板意味着什么（SOP 第 3 节）
- [ ] 原帖内容占比 <30%（SOP 推断的阈值，待复盘验证）
- [ ] 文末固定写：「信息来源：X @账号 原帖，发布于 YYYY-MM-DD（北京时间）」
- [ ] 选帖：≥10 万浏览，48 小时内，不超过 7 天；排除加密货币、财经、AI 办公（SOP 第 1 节）
- [ ] 配图全部自制
