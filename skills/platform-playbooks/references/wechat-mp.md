## 一、机制要点（发前心里过一遍）
- [ ] 新号流量主要来自「推荐（看一看 / 订阅号消息流）」：新榜案例中，几千粉的新号单篇 10 万+，其中 98% 来自「看一看」。【第三方】https://mp.weixin.qq.com/s/9OXM1ds5K9VN0XSuCypcpA
- [ ] 影响推荐的可能因素：在看数、兴趣标签、停留时长、完读率。C 端话题、公共热点、吸睛头图更容易被推荐。【第三方，新榜】同上
- [ ] 不用担心：助推券、删文、真实互关、关闭群发通知、自己刷新，**都不影响推荐**；流量波动正常，先用后台「账号检测」查看状态。【官方，微信公开课转载】https://finance.sina.com.cn/tech/digi/2026-07-22/doc-iniispne4722143.shtml

## 二、爆款结构（对标真实案例拆解）
**对标：数字生命卡兹克**——2026 年 2–7 月发了 131 篇，其中 57 篇 10 万+；96.9% 是第一人称，67.2% 带梗；发文间隔中位数 1 天。https://viyi.cc/docs/ip_khazix_social_media_analysis/03_operational_optimization/

| 案例标题（10 万+） | 结构拆解 | 我们怎么套 |
|---|---|---|
| 《我花499找人上门安装OpenClaw，看到了AI时代最魔幻的一幕。》 | 我花钱/花时间 → 具体动作 → 意外场景 → 观点 | 「我花 X 元/X 小时让 AI 帮门店做 Y，结果……」 |
| 《从0到1带你速通Codex，我整理的终极保姆教程来了。》 | 从 0 到 1 + 保姆教程（收藏型） | 「从 0 到 1，实体老板用 AI 做 X 的保姆教程」 |
| 《AI说不出的随机数，成了鉴别套壳大模型最好的照妖镜。》 | 反常识发现 + 实用结论 | 「我发现 AI 回差评有个致命问题……」 |

**对标：刘润**——《给想用“小龙虾”赚大钱的人泼盆冷水》10 万+、转发 1.4 万以上：热点 + 给普通人的冷静解读。https://newrank.cn/article/detail/34197

**长文骨架（照着写）**
1. 第一屏：一句结论 + 一个实测数字（不写开场白）
2. 我为什么试（门店真实痛点）
3. 过程：步骤截图 3–6 张，每张图配一句解读
4. 结果：前后对比 + 花了多少钱、多少时间
5. 坑：哪里不行（真实）
6. 结尾：一个具体问题 + 请读者点「在看」或转发给同样开店的朋友
- 贴图版：第 1 张 = 结论大字；第 2–8 张 = 步骤；第 9 张 = 总结和提问。

## 三、标题和封面规则
- [ ] 标题用「我花/我让 + 具体动作 + 意外结果」或「保姆教程」句式（对标卡兹克，来源同上 viyi.cc）
- [ ] 标题里必须有具体对象（工具名或门店场景）和数字。经验做法，待复盘验证
- [ ] 话题偏 C 端、偏大众热点，容易进「看一看」【第三方，新榜】https://mp.weixin.qq.com/s/9OXM1ds5K9VN0XSuCypcpA
- [ ] 不做标题党：标题里的承诺，正文第一屏就要兑现。经验做法，待复盘验证
- [ ] 封面：头图要吸睛（同上新榜）；用实测成品图或前后对比图，大字不超过 8 个。字数为经验做法，待复盘验证
- [ ] 风格沿用抖音/视频号已定的 ② luobo 规范 / ③ hybrid，方便跨平台统一。经验做法，待复盘验证
