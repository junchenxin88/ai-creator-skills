# 爆款标题钩子

出封面大字 / 主标题 / 起号选题标题时**必须先跑本技能**。

## 硬规

1. **原句式套用**：对标爆款标题句式一字不拆；只换产品名、可核数字、场景。
2. **禁止**改成说明书腔弱钩（如「本地导出竖屏」「剪片又逼开会员?」软化版）。
3. **数字**必须可核（仓库星数、真测结果）；不能核就写「待实测 / 待复现」，禁止编造。
4. **封面**：痛点砸死 / 知名名字+冲突或硬数字 / 对立句；主钩 ≤10～14 字宜带名字。
5. **开篇公式**：痛点或场景 → 名字登场 → 一个可核对的结果/数字。
6. 禁止虚构模型能力与「隐藏模式教会一切」类欺诈钩；可学骨架，不可编造能力。

## 怎么用

1. 从下方「对标原句式」选一条（或你自己的对标截图句式）。
2. 只替换：产品名、可核星数/参数、场景（剪辑/旁白/图文等）。
3. 对照「已批可用标题库」检查是否撞车或弱化；弱了就重套，不要「润色」。
4. 封面大字从标题里抽「名字+冲突/数字」一行。
